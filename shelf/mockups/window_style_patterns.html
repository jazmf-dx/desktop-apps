テーマ 出したあと

現行は角丸 14px・区切り線あり・行も詰め気味です。4 案とも ウィンドウの角丸を大きく、区切り線を減らし、ボタン類をピル形にしてあります。 各ウィンドウは操作できます：行をクリックで選択、行に乗せると出る「↗」で「ドロップして出した」をシミュレート、ヘッダーの歯車で設定。 上の「出したあと」と歯車の設定は連動します。

A　ほんのり丸く

現行の構造のまま、角丸だけ 14→20px に。最小の変更で「柔らかい」に寄せる案。

○ メリット変更が CSS 中心で小さい。既存の見た目から違和感なく移行できる
△ デメリット劇的には変わらない。「洗練」感は控えめ
ウィンドウ 20px / 行 12px / サムネ 10px 区切り線: ヘッダー・フッターは非表示 ボタン: ピル形（99px）

B　カードを浮かせる

外枠は薄いグレー、リストだけ白いカードに載せる二重角丸。下の「まとめてドラッグ」はアクセント色で主役に。

○ メリット入れ子の丸みで一気に「アプリらしく」なる。階層が明快
△ デメリット内側に余白ができるぶん、リストの有効幅が約 16px 減る
ウィンドウ 26px / リスト面 20px / 行 16px 外側: --hover 色、リスト面: --surface フッターのボタン: accent 塗り

C　ガラス

半透明＋背景ぼかし。背景のデスクトップが透けて、右端に浮かぶ軽い道具に見える。

○ メリットいちばん洗練された印象。画面を圧迫しない
△ デメリットmacOS は vibrancy／Windows は Acrylic が別途必要で実装が重い。背景次第で文字が読みにくい
ウィンドウ 24px / 行 14px 背景: 62% 不透明 + blur(22px) ※ 実装は Tauri の window effects（OS ごとに差）

D　大きく丸く・ゆったり

角丸 30px、行間と余白を広げ、フッターは点線のドロップ枠風に。Yoink に近いしっとりした印象。

○ メリット柔らかさが最も強い。操作対象が大きくて押しやすい
△ デメリット1 画面に載る件数が減る（約 6→5 件）。角が大きいぶん四隅の内容が詰まりやすい
ウィンドウ 30px / 行 18px / サムネ 40px ヘッダー 48px、行の余白 +2px 区切り線なし

おすすめ：B をベースに、角丸だけ D 寄り（26→28px）。CSS だけで両 OS 同じ見た目にでき、洗練されて見えるわりにコストが低いです。C は見栄えは良いものの、Windows 10 では角が四角になる制約もあり、後回しが妥当です。

「出したあと」の設定について

いまもトレイのメニューに「出したら棚から外す」「出したら棚を隠す」があります（既定はどちらもオン）。モックはウィンドウ内の歯車からも同じ設定を変えられる形にしました。実装するなら、トレイのチェックと同じ settings.json の removeAfterUse / hideAfterUse を共有し、歯車は UI を足すだけで済みます。
